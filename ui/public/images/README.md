# Map Images

## Default GTA 5 Map

Place a GTA 5 grayscale map image here as `gta5-map-grayscale.png`.

Recommended sources:
- Search Google Images for "GTA 5 map grayscale" or "GTA 5 satellite map grayscale"
- Suggested image: A high-resolution grayscale satellite view of the GTA 5 map
- Example URL: https://i.imgur.com/F2ZADVF.png (or similar)

The image should be:
- Square aspect ratio (or will be scaled to square)
- High resolution (2048x2048 or higher recommended)
- Grayscale or monochrome
- Shows the entire GTA 5 game world
