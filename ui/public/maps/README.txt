# GTA 5 Map Assets

## Default Map Image

The Map component uses `gta5-map-grayscale.svg` as the default map image.

This is currently a placeholder. To use an actual GTA 5 grayscale map:

1. Find a high-quality GTA 5 map image (recommended: 4096x4096 pixels)
2. Convert it to grayscale
3. Replace `gta5-map-grayscale.svg` with your image (can be .png, .jpg, or .svg)
4. Update the DEFAULT_IMAGE constant in Map.tsx if you change the filename

## Recommended Sources

Search for "GTA 5 map satellite" or "GTA 5 map grayscale" to find suitable images.
The map should ideally be square and high resolution for best zoom quality.
